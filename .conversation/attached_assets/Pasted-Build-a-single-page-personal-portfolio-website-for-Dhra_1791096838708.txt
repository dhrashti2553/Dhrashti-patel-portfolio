2. THE CONCEPT: "THE SUBMISSION DOSSIER"
=====================================================================
The whole site is designed like a polished, modern regulatory submission dossier, in the style of an eCTD package or a Veeva Vault document system, but beautiful and premium, NOT a boring government form. Every section is a "controlled document" in the dossier. The theme should feel precise, trustworthy, organized, and detail-oriented, which are the exact qualities a Regulatory Affairs hiring manager looks for.

Key recurring design elements (use them consistently across the site):
- DOCUMENT HEADER STRIPS: Each section starts with a thin metadata strip in monospace font, e.g.
  "DOC ID: DP-RA-004 | VERSION 2.1 | STATUS: EFFECTIVE | SECTION 4.0: PROFESSIONAL EXPERIENCE"
- STATUS BADGES: Small pill badges like "APPROVED", "EFFECTIVE", "IN PROGRESS", "SUBMITTED", styled like document workflow states.
- APPROVAL STAMP: A circular rubber-stamp style graphic ("APPROVED", with a slightly rotated, ink-textured look) that animates in, stamping down with a slight scale bounce, when certain elements scroll into view.
- SECTION NUMBERING: Navigation and sections use dossier numbering (1.0, 2.0, 3.0…), ALWAYS paired with a plain-English label so recruiters never get confused (e.g. "4.0 Experience").
- Faint background: a very subtle fine grid pattern (like engineering/lab notebook paper) at ~4% opacity.
